- Visual workflow builder based on React Flow.
- Node-based workflow execution engine.
- Conditional branching with IF and Switch nodes.
- Loop execution.
- Wait, Break, Continue, Merge, and No-op workflow nodes.
- HTTP Request workflow node.
- Data transformation and context management nodes.
- AI Agent workflow node.
- OpenAI integration.
- Anthropic integration.
- Groq integration.
- Ollama local inference support.
- Gmail read and send workflow nodes.
- Email workflow support.
- Slack integration.
- Discord integration.
- Telegram integration.
- Reusable application connections.
- Encrypted connection credentials.
- Connection testing for supported integrations.
- Cron-based workflow scheduling.
- Workflow execution history.
- Node-level execution logging.
- Workflow execution cancellation.
- JWT-based authentication.
- PostgreSQL persistence.
- Dockerized frontend and backend services.
- Self-hosted deployment support.
